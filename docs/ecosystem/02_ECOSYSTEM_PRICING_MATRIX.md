## Conclusões globais

### Pode ser padrão

- três níveis como default: Essencial / Pro / Premium;
- Pro como destaque/recomendado;
- herança: Pro inclui Essencial; Premium inclui Pro;
- segurança não entra na comparação comercial.

### Continua vertical/local

- valores;
- anual;
- desconto;
- implantação;
- trial;
- limites;
- add-ons;
- features.

## Anual

Não criar política anual global única.

Há convergência frequente para ~10 mensalidades, mas Dentista usa desconto de 10% e Caravana aprovou anual com lançamento deferred.

## Trial

Não tornar obrigatório.

Há várias verticais com proposta/aprovação de 14 dias, mas Caravana explicitamente não começa com trial público.

## Implantação

Também permanece local:
- algumas verticais: R$ 0/self-service;
- outras: taxa aprovada;
- migração complexa geralmente serviço/add-on.

## Regra para futuras verticais

Começar avaliando:

```text
Essencial / Pro / Premium
Pro recomendado
```

mas o especialista deve justificar qualquer preço/limite com o domínio real.
